# Simple Login System

This repository contains a simple login functionality with unit and integration tests.

## Structure

- `src/`: Contains the source code (`login.py`).
- `tests/unit/`: Contains unit tests (`test_login.py`).
- `tests/integration/`: Contains integration tests (`test_login_integration.py`).
- `docs/`: Contains documentation (`TEST_PLAN.md`).

## Running Tests

To run the unit tests:
```bash
python -m unittest discover -s tests/unit
```

To run the integration tests:
```bash
python -m unittest discover -s tests/integration
```
